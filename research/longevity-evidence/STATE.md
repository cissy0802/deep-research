## 调研线拆法(由题目结构推出,非沿用上期数量)

题目内在结构 = 4 个具名干预 × 「证据分级」这条纵轴。所以 4 条干预线(各自独占一批一手文献)+ 3 条横切线(它们各自独占一类证据,不与干预线抢文献):

| # | 线 | 独占产出的证据类型 |
|---|---|---|
| L1 | ITP 动物金标准台账 | NIA ITP 官方结果表:哪些化合物过了/没过、性别差、剂量与起始年龄、复现状态 |
| L2 | 雷帕霉素 | rapalog 人体试验(PEARL/Mannick 系列)、犬类(Dog Aging Project TRIAD)、线下诊所处方与不良事件 |
| L3 | 二甲双胍 | 糖尿病人流行病学(UKPDS/Bannister)与其后续反转、TAME 状态与经费、运动钝化文献 |
| L4 | NAD+ 前体(NR/NMN) | 人体 RCT(NAD+ 是否升高/结局是否变)、资助方结构、安全性/肿瘤信号 |
| L5 | 禁食/热量限制/限时进食 | CALERIE-2、TRE RCT 与 meta、等热量对照问题、灵长类两项研究的分歧 |
| L6 | 终点与测量层 | 表观遗传时钟作为替代终点的信效度、监管上「衰老」无获批适应症、注册-发表偏倚审计 |
| L7 | 监管与商业现实 | FDA 警告信、NMN 监管身份反转、Loyal 犬用药条件性批准、DTC 生物年龄检测、诊所处方规模 |

重叠检查:L4 只做科学证据,监管/市场全部归 L7(避免 #2 期三线抢同一批文献的教训);L1 只做 ITP 一手表格,四条干预线引用 ITP 时以 L1 为准;L6 只做方法学与注册审计,不重复各干预的具体结局。
