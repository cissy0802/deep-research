## 成文提示
- 必须带的限定:A18–A20 均为非随机样本、单次测量;A21 的分母是「≥10 star 仓库中触及 spec 的 PR」,不含从不改 spec 的仓库(幸存者口径)。
- 禁止的表述:「OpenSpec 用户最活跃/spec-kit 最常被弃」(计数对象不同);「96.6% 的归档 spec 被冻结」;「装了 spec-kit 的仓库有 8% 从未用过」(8% 是下界且只测宪法文件)。
- 最强写法:「在前 60 个装了 spec-kit 的仓库里,28% 没有任何功能 spec;约 18% 出现『spec 停更、代码继续 ≥20 次提交』;在 ≥10 star 仓库的 5,979 个改 spec 的 PR 中,约 80% 同时改了代码」——作为「装了≠用了」与「spec 与代码在同一 PR 共变」的现场核验,不承重于漂移率。
