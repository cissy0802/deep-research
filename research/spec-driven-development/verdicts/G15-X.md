# G15 — Lens X(反证)

**组判定:修正**(H27 引语在 OMG MDA Guide 1.0.1 原件中不存在,按伪引用推翻并替换为原件逐字;核心结论「MDA 承诺由模型再生成代码」成立;H23/H24 得到独立 GitHub 挖掘研究同向支持;H28 数字仍未验证)

搜索角度:① OMG 文档服务器 omg/03-06-01(取得 62 页 PDF,"12th June 2003 MDA Guide V1.0.1");② MDA Guide rev 2.0(ormsc/14-06-01,取得但文本层不可抽取,未核那句是否出自 2.0);③ UML 在开源中的独立测量(Hebig, Ho-Quang, Chaudron, Robles, Fernández, MoDELS 2016;取得作者幻灯片 PDF,se.informatik.uni-rostock.de);④ 不同行业的反向证据(Akdur, Garousi, Demirörs 2018 嵌入式 627 人调查;PDF 下载返回 HTML,仅见搜索摘要);⑤ Kemerer 1992 一手(sites.pitt.edu TLS 失败/WebFetch DNS 失败);⑥ Petre/Hutchinson/Whittle 勘误或作者后续收回(未搜到)。

- **H23 HOLDS(独立同向)**:无勘误。独立测量(不同方法、不同人群):Hebig 等 MoDELS 2016 幻灯片:"1 240 000 nonforked repos (10% of GitHub)… Identified 21 316 UML files 3 295 repositories"(≈0.27% 的仓库含 UML 文件)。口径:幻灯片非论文;计仓库非项目;作者数据集页面另提醒勿据此推断 UML 在开源中的频率。反向:Akdur 等 2018 嵌入式行业调查摘要称多数受访者使用 UML(搜索摘要,**未核**)——行业异质性,成文不得把 Petre 的 50 人推广为「业界不用 UML」。
- **H24 HOLDS(独立同向)**:Hebig 等:"The majority of the UML files (73.33%) are never updated. 26% of the investigated projects updated their UML files at least once."——是「模型-代码不同步」的独立行为测量(不是访谈)。
- **H25 HOLDS**:无反证线索。
- **H26 HOLDS**:无反证;Whittle 的 "MDE may be more widespread than commonly believed" 与 Akdur 方向一致。
- **H27 推翻(引语)/ 核心结论 HOLDS(secondhand → 用原件替换)**:在 MDA Guide 1.0.1 全文(15,256 词)中检索 "enough information" 0 次;原件 §2.2.12 定义为:"A platform independent model is a view of a system from the platform independent viewpoint. A PIM exhibits a specified degree of platform independence so as to be suitable for use with a number of different platforms of similar type."。R1 引语 "contains enough information to drive one or more Platform Specific Models" **不出自 1.0.1**(出处不明,疑为后续版本或二手)——按伪引用处理。可用原件逐字(§1 引言,p.1-1/1-2):"when a new, more fire-resistant type of steel is invented, we can regenerate for the new infrastructure. This is the promise of Model Driven Architecture: to allow definition of machine-readable application and data models which allow long-term flexibility of…";"since the developed models can be used to generate code, they can equally be validated against requirements"。
- **H28 未验证(禁写数字)**:一手未取得。搜索工具对 Kemerer PDF 的解读称文中似有「约 70% 的 CASE 工具在引入一年后不再使用」以及「63 家领先组织中仅 24% 在用 CASE」,但 OCR 残损、无法逐字定位,且未见 25%/5%。维持「未验证」,70/25/5 **禁写**。

## 成文提示
- 必须带:Petre 为 50 人非随机访谈;MDE 调查样本为实践者(幸存者偏差);Hebig 为 GitHub 抽样、计仓库;嵌入式等行业可能相反。
- 禁止:H27 旧引语;「70% 的 CASE 工具一年后被弃用」;「业界几乎不用 UML」(只能说 Petre 样本 35/50 不用)。
- 最强写法:「OMG 2003 年的 MDA 指南把『模型改了就重新生成』写成承诺;十年后,Petre 访谈的 50 名开发者中 0 人全面采用 UML,Hebig 等在约 124 万个 GitHub 仓库中只找到约 3,300 个含 UML 文件,其中 73% 的 UML 文件从未更新。」
