## 成文提示
- 必须带:Google 结果是测试生成子任务、detect@5 口径、单次运行不显著、+38% token;Spec Kit Agents 是 LLM-as-judge、单次运行、作者机构未披露。
- 禁止:「Spec Kit Agents 在 SWE-bench Lite 上证明 SDD +1.7pp」(该对比不含 spec 工件);「spec 驱动测试生成把缺陷检出率提高 9.8pp」(无 k=5 限定);「CodePlan 证明写 plan 有效」。
- 最强写法:「目前唯一在同一仓库、同一模型下比较'Spec Kit 全流程'与'直接实现'的已知数据(Spec Kit Agents Table 1)显示:LLM 评审分 3.51 vs 3.46(1–5 分),完成时间约 1.7 倍;加上仓库探测钩子后 LLM 评审 +0.15,但 60 票人类盲评中更多人偏好无钩子版本。」——单篇、单次、LLM 评审,只能作"未见显著收益"的弱证据。
